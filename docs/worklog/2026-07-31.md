## Phase 4 — 에이전트 루프 + 챗 UI

Claude API 멀티스텝 에이전트 루프(`run_agent_loop`)가 도구를 오케스트레이션하고, React 챗
UI가 플랜/규칙 카드를 렌더한다. 흐름: 챗 입력 → 대상 폴더 인식 → `scan_directory`/`read_content`
→ `propose_plan` → PlanReview 승인 → `execute_plan`.

### 확정한 설계 결정 (§ 인계 §2)

| # | 결정 | 근거 | 기록 |

## 2026-07 신뢰성 세션 — 발견·수정한 결함 4건

실사용 검증에서 드러난 결함을 근본 원인까지 추적(코드 전수)해 수정했다.

**① B1 — "완료 — 이동 undefined개…" (commit `dde769f`)**
- 근본 원인: `execute_plan`이 `PartialExecute` 시 `moved/staged/renamed` 대신
  `completed/failed_op/error`를 반환하는데, 프론트가 `partial`을 무시하고 무조건 성공("완료")으로
  렌더 → undefined 카운트.
- **(b) confirm 게이트 위반은 코드로 배제**: "완료" 경로는 사용자 "실행" 클릭 →
  `confirm_plan` → `execute_plan` 뿐(I1 회귀 테스트로 보강). 승인 없이 못 뜬다.
- 수정: `ExecPlanResponse` 판별 유니온(→ tsc가 partial 분기 강제). partial이면 모달 유지 +
  실패 배너 + 되돌리기/닫기.

**② 플랜 미출력 (commit `4e34441`)**
- 근본 원인: `read_content`가 많은 요청에서 모델이 프로즈를 쓰다 `max_tokens=1024`에서
  절단(`stop_reason=max_tokens`), `propose_plan` 호출 전에 끊김. 루프는 잘린 프로즈를 최종
  text로 반환 → 카드 미표시.
- 수정: max_tokens 1024→4096. 루프가 `max_tokens` 절단을 처리(tool_use 없이 잘리면 완료
  오인 없이 nudge 후 계속, MAX_STEPS로 무한루프 방지).

**③ undo 빈 폴더 잔재 (commit `2bc8729`) → ADR-0009**
- 근본 원인: `move_file`의 `create_dir_all`로 생긴 목적지 폴더를 undo가 못 지움(저널 기록 없음).
- 수정: `JournalEntry.created_dirs`(execute가 신규 폴더 기록) + `remove_empty_dir`(빈 폴더만) →
  undo가 깊은 것부터 제거. 기존 폴더는 보존.

**④ 유령 중복본 (파일 10개인데 17-op, commit `9a5f39f`) → ADR-0009**
- 근본 원인: `scan_directory`/`tool_scan`이 UPSERT만 하고 사라진 파일 행을 prune 안 함 →
  stale 인덱스가 같은 content_hash를 현재+유령 두 벌로 노출 → 에이전트가 없는 중복본 탐지.
- 수정: `scanner::scan_and_prune` mark-sweep(스캔 후 last_seen 오래된 root 하위 행 삭제). FE와
  에이전트 `tool_scan`이 공유.

## 후속 — P-3(문서화) · P-1(충돌 탐지)

세션이 길어져 체크포인트로 기록한다.

- **P-3** — 위 "신규 ADR" 4건 + 이 워크로그로 해소.
- **P-1 충돌 탐지 (제안 시점 미리보기)** — `op.conflict`가 항상 None이라 PlanReview "이름충돌"
  배지가 휴면이었다. `Engine::propose`가 Move/Rename op의 목적지 존재(`fileops.exists`)를 검사해
  `conflict=Rename`을 채우도록 추가. FE 배지·`risk_score`·에이전트 직렬화가 이미 conflict를
  소비해 **프론트 변경 없이 관통**. 실제 리네임(C4)은 여전히 execute의 `resolve_conflict` —
  제안은 미리보기, execute는 권위(→ **ADR-0010**). TDD 회귀 3건. commit `91e41ab`.
