# ADR-0006 — 에이전트 툴 카탈로그 안전 경계 (execute·undo·apply_rule_change 배제)

| 항목 | 내용 |
|------|------|
| **상태** | 수용됨 (Phase 4 에이전트 루프, 2026-07) |
| **결정자** | 프로젝트 오너 |
| **관련** | ADR-0004(LLM은 proposed_dest만), ADR-0003(staging) |

---

## Context

Phase 4에서 LLM(Claude API)이 멀티스텝 **에이전트 루프**로 도구를 오케스트레이션한다.
`run_agent_loop`이 `stop_reason=tool_use`를 받으면 `dispatch_tool()`로 도구를 실행하고
결과를 다시 LLM에 돌려주며 반복한다.

ADR-0004는 "LLM 출력은 `files` 메타데이터만 채우고 실행은 게이트"라는 원칙을 세웠다.
그러나 P4에서 LLM이 **능동적으로 도구를 호출**하게 되면서, "어떤 도구를 LLM 손에 쥐여줄
것인가"가 새로운 안전 경계가 되었다. 비가역·파괴적 연산을 도구로 노출하면 확률적 LLM이
그것을 스스로 호출할 수 있다.

핵심 위험 연산:
- **execute / execute_plan** — 실제 파일 이동(비가역).
- **undo** — 방금 실행한 정리를 되돌림. 자동 호출되면 사용자 의도와 무관하게 상태가 뒤집힌다.
- **apply_rule_change** — ORGANIZER.md(사용자 정리 규칙)를 덮어씀. 파일 이동과 동등한 무게.

---

## Decision

**에이전트가 스스로 호출할 수 있는 도구는 "제안(propose)"과 "읽기(read)"뿐이다.
실행·되돌림·규칙 반영은 툴 카탈로그(`tool_schemas()`)에 존재하지 않는다.**

LLM에 노출되는 도구:
- `scan_directory`, `list_files`, `read_content` (읽기)
- `propose_plan`, `propose_rule_change` (제안 — 사용자 승인 게이트 앞에서 멈춘다)

LLM에 **절대 노출되지 않는** 연산 (Tauri 커맨드로만 존재, 프론트엔드가 사용자 클릭으로 호출):
- `confirm_plan` / `execute_plan` — 사용자가 PlanReview에서 "실행"을 눌러야만.
- `undo_plan` — 사용자가 `/undo` 또는 모달 되돌리기를 눌러야만.
- `apply_rule_change` — 사용자가 RuleReview에서 승인해야만.

불변식으로 고정:
- **I1** — execute·execute_plan은 `tool_schemas()`에 없다. 회귀 테스트
  `agent.rs::i1_execute_not_in_tool_catalog`가 두 이름의 부재를 단언한다.
- **I2** — undo는 사용자 트리거 전용. `run_agent_loop`이 LLM의 `undo` tool_use 시도를
  `is_error` tool_result로 거부한다("에이전트 자율 호출 차단"). sentinel 테스트로 증명.
- **R1–R3** — 규칙 변경은 파일 이동과 동등한 게이트. `apply_rule_change`도 카탈로그 밖.
- **단일 게이트** — `dispatch_tool()`이 모든 LLM 도구 실행의 유일한 분기점이다. 우회 경로를
  만들지 않는다.

---

## Consequences

**긍정**

- LLM이 아무리 잘못된 추론을 해도 파일을 움직이거나 되돌리거나 규칙을 덮어쓸 수 없다.
  최악의 출력은 "잘못된 제안"이며, 그것은 사용자 승인 게이트에서 걸러진다.
- ADR-0004의 구조적 보장이 능동 에이전트 루프에서도 유지된다.
- "제안 → 승인 → 실행"의 게이트가 코드 구조로 강제되어, 프롬프트 튜닝 실수로 무너지지 않는다.

**비용**

- 완전 무인 자동화(제안 즉시 실행)는 불가능하다. 사용자 confirm이 항상 필요하다.
- LLM이 "제안했으니 실행됐겠지"라고 착각하는 응답을 낼 수 있어(§ 세션 B1), 프론트엔드가
  실행 상태를 정확히 구분해 렌더해야 한다.

**관련 코드 경로**

- `src-tauri/src/agent.rs::tool_schemas()` — 노출 도구 목록. execute/undo/apply_rule_change 없음.
- `src-tauri/src/agent.rs::run_agent_loop` — undo tool_use 거부(I2), `dispatch_tool` 단일 분기.
- `src-tauri/src/agent.rs::i1_execute_not_in_tool_catalog` — I1 회귀 테스트(sentinel).
- `src-tauri/src/lib.rs` — `execute_plan`/`confirm_plan`/`undo_plan`/`apply_rule_change` Tauri 커맨드(FE 전용).
