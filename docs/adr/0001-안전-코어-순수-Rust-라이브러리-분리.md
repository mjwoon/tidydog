# ADR-0001 — 안전 코어를 외부 의존성 0의 순수 Rust 라이브러리로 분리

| 항목 | 내용 |
|------|------|
| **상태** | 수용됨 (Phase 2, 2026-06-29) |
| **결정자** | 프로젝트 오너 |

---

## Context

TidyDog의 핵심 가치는 **"파일을 잃지 않는다"**. propose→confirm→execute→undo 게이트, 스코프 가드, 충돌 리네임 같은 안전 로직이 Tauri 프레임워크, SQLite, 실제 파일시스템에 직접 결합되어 있으면 다음 문제가 생긴다.

1. **단위 테스트 불가**: FS 작업이 섞이면 "게이트가 실제로 차단하는가"를 파일 없이 검증할 수 없다.
2. **의존성 오염 위험**: `tauri`, `rusqlite`, `reqwest` 같은 외부 크레이트가 안전 로직에 진입할 수 있다. 의존성 업그레이드 한 번에 안전 동작이 바뀔 수 있다.
3. **구조적 우회 가능성**: 안전 코드와 어댑터 코드가 같은 크레이트에 있으면 컴파일러가 우회를 막지 못한다.

Phase 1 초기에 `crates/tidydog-core`는 `core_version()` 반환 스텁만 있었다.

---

## Decision

`crates/tidydog-core`를 **외부 의존성 0의 순수 Rust 라이브러리**로 확립한다.

**핵심 구조**:
- `Guard` 트레이트 / `ScopeGuard`: 화이트리스트 + 블랙리스트 + 심링크 탈출 차단
- `Store` 트레이트 / `FileOps` 트레이트: 부수효과 인터페이스만 정의, 구현체 없음
- `Engine<G, S, F>`: propose → confirm → execute → undo 게이트 로직 전부

`Cargo.toml`(`crates/tidydog-core/Cargo.toml`):
```toml
[dependencies]
# 비어 있음 — 외부 의존성 0
```

실제 FS/DB 구현(`FsFileOps`, `SqliteStore`, `AppGuard`)은 모두 `src-tauri/src/`에 있다. `tidydog-core`는 `src-tauri`를 모른다.

테스트용 인메모리 fake(`FakeStore`, `FakeFileOps`)는 `tidydog-core/src/lib.rs`의 `pub mod testing`에 둔다. 실 FS/DB 없이 게이트 전체를 테스트한다.

---

## Consequences

**긍정**

- 실 FS/DB 없이 안전 속성 전체를 단위 테스트 가능.  
  → `tests/gate.rs` 15개, `tests/scope_guard.rs` 6개, `tests/preview.rs` 5개 (총 26개).
- **"위험 능력을 구조로 제거"**: `tidydog-core`에 `reqwest`, `rusqlite` import가 컴파일 오류이므로, 안전 코어가 네트워크·DB에 접근하는 것은 구조적으로 불가능하다.
- Phase 3에서 `ContentReader`, `Summarizer` 트레이트를 코어에 추가해도 외부 의존성이 들어오지 않는다 (`content.rs`, `summary.rs`).

**비용**

- 어댑터 보일러플레이트: `SqliteStore`, `FsFileOps`가 각각 `Store`, `FileOps` 트레이트를 수동으로 구현해야 한다 (`src-tauri/src/store.rs`, `src-tauri/src/fileops.rs`).
- 트레이트 경계 설계 비용: 인터페이스 변경 시 코어 트레이트와 fake, 어댑터를 동시에 수정해야 한다.

**관련 코드 경로**

- `crates/tidydog-core/src/gate.rs` — Engine 구현
- `crates/tidydog-core/src/ops.rs` — Store, FileOps 트레이트
- `crates/tidydog-core/src/lib.rs::testing` — FakeStore, FakeFileOps
- `src-tauri/src/store.rs` — SqliteStore 어댑터
- `src-tauri/src/fileops.rs` — FsFileOps 어댑터
